# 真机调试（Expo Go）

目标：改代码后，手机上的 App 一两秒内自动刷新。不需要 Android SDK 或 Xcode。

## 原理

```
电脑：npx expo start  ──(Metro 打包服务，JS 代码)──▶  手机：Expo Go
```

- **Expo Go** 是一个现成的 App，里面已经装好了常用的原生模块（包括本项目用的 AsyncStorage）。
- 电脑上的 **Metro** 把你的 TypeScript 打成 JS，通过网络发给 Expo Go 执行。
- 所以只改 JS 时不需要重新打包 App。这就是"热更新"。

## 第 1 步：手机装 Expo Go

- iPhone：App Store 搜 "Expo Go"。
- Android：Google Play 搜 "Expo Go"；没有 Google Play 时，到 <https://expo.dev/go> 下载 APK。
- 商店里的 Expo Go 只支持**最新的一个** SDK。本项目用 **SDK 58**（看 `package.json` 里 `expo` 的版本）。
  - 提示版本不匹配时，先升级 Expo Go。
  - 升级后还不匹配，说明 Expo 已经发布了更新的 SDK。这时把项目升级到新 SDK（`npx expo install expo@latest && npx expo install --fix`），或者改用开发构建。

## 第 2 步：启动开发服务

选一种网络方式。

### 方式 A：在 Mac 上跑（推荐，最快）

Mac 和手机连同一个 Wi-Fi。

```bash
git clone <仓库地址> && cd ledger-app
npm install
npx expo start
```

### 方式 B：在 WSL 上跑（用隧道）

WSL2 的网络在 Windows 后面，手机连不到它的 IP，所以要走隧道：

```bash
npm install
npm run start:tunnel
```

第一次运行会提示安装 `@expo/ngrok`，选 yes。隧道走公网，国内网络可能慢或连不上；连不上就用方式 A。

## 第 3 步：扫码

- iPhone：用系统相机扫终端里的二维码，点弹出的链接。
- Android：打开 Expo Go，点 "Scan QR code"。

## 第 4 步：验证

1. 记一笔支出、一笔收入。看顶部的收入、支出、结余是否对。
2. 长按一条记录，删除。
3. **彻底关掉 Expo Go**（从后台划掉），再打开项目：数据还在。
4. 改一下 `App.tsx` 里的某个文字，保存：手机上马上变化。

## 常用操作

| 操作 | 怎么做 |
|---|---|
| 打开开发菜单 | 摇一摇手机；或在终端按 `m` |
| 手动刷新 | 终端按 `r` |
| 看 `console.log` | 直接显示在跑 `expo start` 的终端里 |
| 红屏报错 | 看报错里的文件和行号，改完保存会自动消失 |

## Expo Go 的边界

Expo Go 里没有的原生库（比如某些支付、推送 SDK）在 Expo Go 里用不了。那时要做"开发构建"（development build），等于自己打一个带这些库的 Expo Go。本项目 MVP 用不到。
