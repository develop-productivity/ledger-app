# 打包并装到自己手机上

Expo Go 是"借别人的壳跑自己的 JS"。打包是做出**自己的 App**：有自己的图标、名字，不依赖 Expo Go，也不依赖电脑开着。

| 平台 | 方式 | 在哪台电脑 | 花费 |
|---|---|---|---|
| Android | EAS 云端打 APK | WSL 或 Mac 都行 | 免费（免费账号每月有构建次数限制） |
| iOS | Xcode 本地构建，免费 Apple ID 签名 | 只能 Mac | 免费，但 7 天后过期 |

## Android：EAS 云端打 APK

APK 在 Expo 的云服务器上构建，所以本机不需要 Java 和 Android SDK。

1. 注册 Expo 账号：<https://expo.dev/signup>（这一步要人来做）。
2. 登录：

   ```bash
   npx eas-cli@latest login
   ```

3. 第一次构建前关联项目（会在 `app.json` 里写入 `extra.eas.projectId`，这个改动要提交）：

   ```bash
   npx eas-cli@latest init
   ```

4. 构建：

   ```bash
   npx eas-cli@latest build -p android --profile preview
   ```

   - 第一次会问是否生成签名密钥（Android Keystore），选 yes，EAS 会替你保管。
   - 排队加构建一般 10～30 分钟。终端会给出构建页面链接。

5. 安装：构建完成后，终端和构建页面都有二维码和下载链接。用手机浏览器打开，下载 APK，安装。
   - 系统会提示"禁止安装未知来源应用"，按提示允许浏览器安装。

`--profile preview` 对应 [eas.json](../../eas.json) 里的 `preview`：`buildType: apk` 表示出 APK（能直接装），而不是上架 Google Play 用的 AAB。

## iOS：在 Mac 上用 Xcode 装到 iPhone

EAS 给真机出 iOS 包需要付费 Apple 开发者账号（99 美元/年）。不上架时，用免费 Apple ID 在本地签名更合适。

**这一节交给 Mac 上的 Claude session 来做。**

前提：Mac 已装 Xcode（App Store 下载），已装 Node（建议用 nvm）。

1. Xcode → Settings → Accounts，点 `+` 登录自己的 Apple ID。
2. iPhone 用数据线连 Mac，在手机上点"信任此电脑"。
3. iPhone 打开 设置 → 隐私与安全性 → 开发者模式，打开，按提示重启。
4. 在 Mac 上：

   ```bash
   git clone <仓库地址> && cd ledger-app
   npm install
   npx expo run:ios --device --configuration Release
   ```

   - 命令会先生成 `ios/` 原生工程（`ios/` 已在 `.gitignore` 里，不要提交），再用 Xcode 编译。
   - 列出设备时选你的 iPhone。
   - 如果报签名错误：用 Xcode 打开 `ios/*.xcworkspace`，选 target → Signing & Capabilities，Team 选 "（你的名字）(Personal Team)"，再运行一次命令。
   - 如果报 bundle ID 已被占用：把 `app.json` 里的 `ios.bundleIdentifier` 改成别的（如加上你的名字），删掉 `ios/` 后重跑。
   - `--configuration Release` 把 JS 打进 App 里，断开电脑也能用。不加时是调试版，要连着 Metro。

5. 第一次打开 App 会提示"不受信任的开发者"：设置 → 通用 → VPN 与设备管理 → 点你的 Apple ID → 信任。

**7 天限制**：免费签名 7 天后过期，App 打不开。重新执行第 4 步即可，数据不会丢。

## 打包之后要知道的事

- 改了 JS 代码，手机上的 App **不会**自动更新，要重新打包、重新安装（或以后接入 `eas update` 做热更新）。
- 改 `app.json` 里的名字、图标、包名，也要重新打包。
- `android.package` 和 `ios.bundleIdentifier` 是 App 的身份证。装上以后再改，系统会当成另一个 App。
