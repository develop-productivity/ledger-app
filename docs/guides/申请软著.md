# 申请软件著作权（软著）

在中国版权保护中心网上登记，**全程在线、免费**，受理后 60 日内审完。依据和来源见 [国内上架调研](../research/2026-11-17-china-stores.html) 第三节。

华为对非游戏应用不强制软著，但 vivo、应用宝等通常要。提交了软著，**商店里的应用名要和软著的名称或简称一致**，所以名称定为：全称"记账本软件"，简称"记账本"，商店上架名用"记账本"。

## 1. 准备材料（我来做）

材料由脚本生成，放在 [docs/copyright/](../copyright/)：

| 文件 | 内容 |

| `记账本软件V1.4.0-源程序.pdf` | `src/` 下全部源代码，去掉空行，每页 50 行，页眉写"记账本软件 V1.4.0"和页码。不到 60 页，全部提交 |
| `记账本软件V1.4.0-用户手册.pdf` | 功能说明和操作步骤，配截图 |

重新生成（代码改了、版本号变了都要重新生成）：

```bash
npx expo start --web --port 8099          # 另一个终端，用户手册的截图要用
node scripts/copyright/make.js            # 需要 playwright-core，装法见 scripts/store/README.md
```

**申请前确认**：v1.4.0 已经合并并发版；隐私政策里的开发者姓名、联系邮箱已经填好（改了 `src/i18n/legal.ts` 要重新生成源程序 PDF）。材料里的软件名称、版本号必须和申请表一致。

## 2. 注册和实名认证（你来做）

1. 打开中国版权保护中心的登记系统：<https://register.ccopyright.com.cn/>（入口以官网 <https://www.ccopyright.com.cn/> 为准）。
2. 注册账号，选**个人**，按页面要求做实名认证（身份证信息等）。认证约 1～3 个工作日。

### 开发目的

> 为个人用户提供一款不联网、不收集个人信息的记账工具，帮助用户随时记录日常收入和支出，了解自己的消费结构，并能自行备份和导出数据。

### 面向领域 / 行业

> 个人生活、个人财务记录。

### 主要功能

> 1. 记账：记录支出和收入，支出 10 个分类、收入 5 个分类，可填写备注、选择日期，可修改和删除记录。
> 2. 明细：按月份显示本月结余、收入、支出，记录按日期分组并显示每日收支合计。
> 3. 统计：按分类显示占比环形图和金额排行，按日期显示每日柱状图，可切换支出和收入。
> 4. 数据管理：把全部记录备份为文件，从备份文件合并恢复，导出 CSV 表格。
> 5. 偏好设置：界面语言（跟随系统、中文、英文），货币符号（自动或手动选择）。
> 6. 隐私保护：首次启动征求用户同意，软件内查看用户协议和隐私政策，可撤回同意。

### 技术特点

> 1. 采用 React Native 跨平台框架和 TypeScript 语言开发，一套代码同时支持 Android 和 iOS。
> 2. 单机运行：安装包移除了网络权限，所有数据只保存在手机本地，断网时全部功能可用。
> 3. 金额以整数"分"存储和计算，避免浮点误差；业务逻辑写成纯函数，配有 100 多个自动化测试。
> 4. 数据写入采用串行队列，数据损坏时自动备份原数据，避免记录丢失。
> 5. 备份恢复按记录编号合并，只新增不覆盖，重复恢复不产生重复记录；整份文件校验，损坏文件不导入。
> 6. 界面文字、日期格式、货币符号按语言和地区切换。

字数限制以系统页面为准，超了就删掉后面几条。

## 4. 上传材料、签字、提交（你来做）

1. 上传 `docs/copyright/` 里的两份 PDF：源程序和用户手册（文档）。
2. 在线打印"申请确认签章页"，**本人签字**，扫描成 PDF 上传。
3. 提交。之后在系统里看进度。

## 5. 之后

- 收到补正通知：30 日内按要求改好重新提交，逾期视为撤回。
- 拿到证书（PDF 电子证书）后：上传到华为 AGC 的资质一栏；以后上 vivo、应用宝也用它。
- 证书上的名称是"记账本软件"，简称"记账本"。商店上架名用"记账本"，和简称一致。
