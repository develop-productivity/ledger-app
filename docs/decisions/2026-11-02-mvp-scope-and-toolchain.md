# 记账本 MVP 的范围和工具链

2026-11-02 · 拍板：用户（工具链细节由 Claude 定）· 状态：生效

## 决定

用 Expo（React Native）做一个只存本地的记账本，目的是走通"真机调试 → 打包 → 装到自己手机"，不上架、不变现。

## 为什么

1. 用户要学原生 App 的工具链，选"跨平台框架 + 小项目"这条省力路线（用户在对话中选定 React Native 和记账本）。
2. 开发机 WSL 不能装 Android SDK / Xcode；Expo Go 和 EAS 云构建绕开了这个限制。
3. iOS 用 Mac + 免费 Apple ID 本地签名，不买 99 美元/年的开发者账号。
