# 目录按职责分层，测试放 tests/

2026-11-08 · 拍板：用户（要求目录分明、测试和主代码分开；分层细节由 Claude 定）· 状态：生效

## 决定

`src/` 按职责分成 `app/`（页面）、`components/`、`core/`（纯函数）、`services/`（存储和系统）、`state/`、`ui/`；单元测试移到根目录 `tests/`，子目录和 `src/` 对应；import 用 `@/` 别名。

## 为什么

1. 文件从 2 个长到 10 多个，平铺在 `src/` 下看不出谁是纯逻辑、谁碰存储和系统。
2. 测试和主代码分开，找代码和找测试都更快；`core/` 不依赖其他目录，单测不用模拟原生模块。
3. 别名让文件移动时 import 不用跟着数 `../`。`src/app/` 是 Expo Router 规定的位置，不移。
