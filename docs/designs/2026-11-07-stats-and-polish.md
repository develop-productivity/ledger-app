# v1.1.0：统计页和界面打磨

2026-11-07 · 作者：Claude · 状态：已实现

## 问题

v1.0.0 只有一个界面，表单和列表挤在一起，看起来像练习作品。用户要求：加饼图，让 App 看起来接近市面上成熟的记账 App。

## 范围

做：

1. **两个标签页**：「明细」和「统计」，底部标签栏切换。
2. **明细页**：顶部是本月结余卡片（结余大字，收入、支出小字）。列表按天分组，每组标题显示日期、星期和当天收支。每条记录带彩色分类图标。右下角是悬浮的"+"按钮。
3. **记一笔页**：从底部弹出。大号金额输入框，分类图标网格，日期可以往前调，备注。
4. **编辑和删除**：点一条记录进入编辑；编辑页有删除按钮。长按删除保留。
5. **统计页**：按月、按支出或收入看：
   - 环形饼图，中间显示总额；
   - 分类排行，带百分比和进度条；
   - 每日柱状图。
6. **分类扩充**：支出加"医疗、学习、人情、通讯"，收入加"理财、红包"。旧分类名不变，旧数据照常显示。

不做：预算、多账本、导出、云同步、深色模式、自定义分类。

## 方案对比

### 导航

| 方案 | 结论 |
|---|---|
| **Expo Router** | 选用。项目 AGENTS.md 规定加第二个界面时用它；包含在 Expo Go 里 |
| 自己用状态切换页面 | 没有返回手势、没有弹出动画，不像成熟 App |

### 饼图

| 方案 | 结论 |
|---|---|
| **react-native-svg 自己画** | 选用。环形图用多个 `Circle` 加 `strokeDasharray` 实现，计算是纯函数，可以单测；包含在 Expo Go 里 |
| 图表库（victory-native 等） | 体积大，部分依赖 Skia 等原生库，Expo Go 里可能用不了 |

### 图标

用 `@expo/vector-icons` 的 Ionicons，包含在 Expo Go 里。它依赖 `expo-font`，必须直接装进项目；expo-doctor 提示过，少了它，打包后的 App 可能崩溃。

### 记一笔页的顶栏

自己画（关闭、标题、删除），不用导航自带的头部。原因：Web 上的导航头会忽略自定义的 `headerLeft`，三端表现不一致。

安装时遇到的问题：expo-router 间接依赖 `react-dom`，npm 默认装 19.3.1，它要求 react 19.3.1，和项目的 19.3.0 冲突。解决：用 `npx expo install react-dom react-native-web` 装 SDK 匹配的 19.3.0。`react-native-web` 同时让项目能在浏览器里预览。

## 数据

存储格式不变（`version: 1`），不需要迁移。新增的只是分类名，旧版本 App 读到新分类名也能正常显示文字。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/app/_layout.tsx` | 根布局：数据提供者 + Stack（标签页、记一笔弹窗） |
| `src/app/(tabs)/_layout.tsx` | 底部标签栏 |
| `src/app/(tabs)/index.tsx` | 明细页 |
| `src/app/(tabs)/stats.tsx` | 统计页 |
| `src/app/entry.tsx` | 记一笔 / 编辑 |
| `src/LedgerContext.tsx` | 读写数据、当前月份，供各页面共享 |
| `src/ledger.ts` | 纯函数（已有），加更新、删除、日期加减、日期标签 |
| `src/chart.ts` | 纯函数：分类占比、环形图分段、每日合计 |
| `src/categories.ts` | 分类的图标和颜色 |
| `src/theme.ts` | 颜色、圆角等 |
| `src/components/` | 月份切换、分类图标、环形图等组件 |

`App.tsx`、`index.ts` 删除，入口改为 `expo-router/entry`。

## 风险和回滚

| 风险 | 处理 |
|---|---|
| 从 v1.0.0 升级后数据丢失 | 存储键和格式都不变；签名密钥由 EAS 保管，versionCode 改为 2，可以覆盖安装 |
| 编辑时改了日期，记录跑到别的月份 | 保存后，月份切到这条记录所在的月份 |
| 日期调到未来 | 日期最多调到今天 |
| 环形图只有一个分类（100%）时画不出来 | 用描边圆实现，一段占满整圈也能画；有单测 |
| 加了原生库，旧的 APK 不能直接用 | 本来就要重新打包；Expo Go 里都包含这些库，真机调试不受影响 |

回滚：撤销这个 PR，数据格式没变，旧版本能读新版本写的数据。

## 怎么验证

1. `npm run check`：类型检查 + 单元测试（新增 `chart.ts` 和 `ledger.ts` 新函数的测试）。
2. `npx expo export --platform android` 能打包；`npx expo-doctor` 通过。
3. 浏览器预览（`npx expo start --web`）截图看界面。
4. 真机：Expo Go 扫码，走一遍记一笔、编辑、删除、切月份、看统计。
