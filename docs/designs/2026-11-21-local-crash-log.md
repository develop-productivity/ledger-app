# v1.4.0：本机崩溃诊断

2026-11-21 · 作者：Claude · 状态：已实现

## 问题

线上出问题时，开发者看不到任何线索：用户反馈"闪退了"，你无法知道是什么错、在哪个版本、什么机型上出的。常见做法是接 Sentry 之类的崩溃上报服务，它会自动把堆栈上传到服务器。

但 v1.4.0 的路线是[国内应用商店](../decisions/2026-11-17-china-stores.md)，华为把"完全断网时所有功能都能用"的 App 认定为单机 App，可以不办 App 备案；**审核识别到联网就驳回**。崩溃上报要联网，和这条路线正面冲突。

所以选第三种做法：崩溃信息只记在本机，用户能导出成文件，自己决定发不发、发给谁。

## 方案

| 项 | 做法 |
|---|---|
| 记录哪些内容 | 时间、App 版本、错误类型和消息、堆栈前 8 行、系统版本、设备型号、React Native 版本 |
| 怎么记录 | 在 `src/app/_layout.tsx` 模块顶层调用 `installCrashHandler()`，包住 `ErrorUtils` 的全局错误处理器，记完再交给原来的处理器（红屏和原有错误展示不变） |
| 存哪 | AsyncStorage 键 `ledger.crashlog.v1`，最多 10 条，超过丢最旧的。不进备份文件 |
| 隐私 | 存之前清洗：引号内容、数字、中文和全角字符都遮掉。错误消息常把值拼在引号里（如 `Cannot read "餐饮"`），金额是数字，分类和备注是中文，三者一起遮 |
| 用户入口 | 「我的」→「诊断」：显示条数（或"没有记录到崩溃"），点击导出。有记录时下面多一行"清除记录" |
| 导出 | 和备份、CSV 一样的路径：Android 可以选存到手机文件夹或分享给其他 App，iOS 走分享面板，网页预览走浏览器下载 |

### 文件

| 文件 | 作用 |
|---|---|
| `src/core/crashlog.ts` | 纯函数：清洗、截断、序列化、解析、导出格式。有单测 |
| `src/services/crashlog.ts` | 全局错误钩子、读写 AsyncStorage、读设备信息 |
| `tests/core/crashlog.test.ts` | 清洗规则、非法数据处理、上限、导出格式 |

## 方案对比

| 问题 | 选用 | 没选 | 理由 |
|---|---|---|---|
| 崩溃上报还是本地日志 | 本地日志 | Sentry 等崩溃上报服务 | 国内商店单机路线要求不联网；上报服务还要交出联网权限，隐私政策要改成"会收集数据" |
| 记录内容清洗到什么程度 | 引号、数字、中文全遮 | 只遮已知的敏感字段 | 记日志时拿不到"哪些字段是用户输入"；宁可多遮，也要保证导出文件里没有任何账目内容 |
| 堆栈里的数字要不要遮 | 不遮 | 一律遮 | 堆栈是文件路径和行号（如 `index.bundle:1:45231`），不含用户数据，遮了反而没法排查 |
| 上限多少条 | 10 | 100、不限制 | 只用来排查最近的问题，10 条够；日志越多占的存储越大 |

### 不做

- 崩溃率和趋势统计：要汇总就得联网，和单机路线冲突。等以后有需要再单独决定。
- 自动分享：导出后交给系统分享面板，由用户自己选发给谁。
- 对"卡顿"和"页面停留"之类的性能事件做记录：和崩溃排查无关，扩大范围。

## 风险和回滚

| 风险 | 处理 |
|---|---|
| 全局错误钩子自己出错，导致崩溃"连环炸" | 写日志失败时吞掉并打 `console.warn`，再交给原来的处理器；单测覆盖非 Error 对象、循环引用、坏数据 |
| 清洗漏掉某种用户输入 | 规则是"引号 + 数字 + 中文"三条一起上，覆盖了账目会出现的所有字符类别；即使漏了，日志也不出手机 |
| 老用户升级后突然看到同意页 | 政策加了崩溃日志说明，`POLICY_VERSION` 从 1 加到 2，v1.4.0 本来就要重新同意，不多一次 |
| 日志把存储撑大 | 最多 10 条、每条消息 300 字、堆栈 8 行；用户可以随时清除 |

回滚：去掉 `_layout.tsx` 里的 `installCrashHandler()` 调用和「我的」里的诊断区。`ledger.crashlog.v1` 是单独的键，留着不影响旧版本。

## 怎么验证

1. 单测：`npx jest tests/core/crashlog.test.ts`。
2. 网页预览：清空存储，在控制台制造一次错误（如 `setTimeout(() => { throw new Error('test') })`），回到「我的」看诊断条数变成 1；点导出，看文件里是 `Error: test`，没有中文和数字。
3. APK 上：同样制造一次错误，确认红屏照常出现、日志记下来了；点导出走一遍存到文件夹和分享两条路径。
4. 提交国内商店前：确认导出文件里找不到任何金额、备注、分类的内容。
