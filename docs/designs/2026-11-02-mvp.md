# 记账本 MVP 设计

2026-11-02 · 作者：Claude · 状态：已实现

## 问题

用户想走一遍移动 App 的工具链：真机调试 → 打包 → 装到自己手机上。不上架，不变现。
需要一个足够小、但有真实数据流的 App。选定"记账本"。

限制：

- 开发机是 WSL，没有 Java、Android SDK、Xcode，也不能装软件。
- 用户另有一台 Mac（M1），可以装 Xcode。
- 不需要服务器。数据只存在手机本地。

## 功能范围（MVP）

1. 记一笔：选"支出 / 收入"，输入金额，选分类，可选备注。日期取当天。
2. 按月查看：切换月份，显示本月收入、支出、结余。
3. 列表：本月的记录，新的在上，按日期分组。
4. 删除：长按一条记录，确认后删除。
5. 数据在 App 关闭后仍在。

不做：编辑记录、自定义分类、图表、导出、云同步、多币种、登录。

## 方案对比

### 框架

| 方案 | 优点 | 缺点 |
|---|---|---|
| **Expo（React Native）** | React Native 官方推荐；手机装 Expo Go 扫码就能真机调试，不需要本地 SDK；EAS 云端打包 | 用了不在 Expo Go 里的原生库就要做开发构建 |
| 裸 React Native CLI | 完全控制原生工程 | 本地必须有 Android SDK / Xcode，WSL 装不了 |
| Flutter | 性能好 | 要学 Dart；本地同样需要 SDK |

选 Expo：唯一能在这台 WSL 上直接开发的方案，而且和用户已有的 React 知识衔接。

### 存储

| 方案 | 优点 | 缺点 |
|---|---|---|
| **AsyncStorage** | 键值存储，API 最简单，包含在 Expo Go 里 | 整份读写，数据量大时慢 |
| expo-sqlite | 能查询、能分页 | 要写 SQL 和迁移，MVP 用不上 |

选 AsyncStorage。个人记账一年几千条，整份 JSON 读写没有问题。数据格式带 `version` 字段，以后换 SQLite 时可以迁移。

### 打包与安装

| 平台 | 方式 | 需要什么 |
|---|---|---|
| Android | `eas build -p android --profile preview` 云端出 APK，手机打开下载链接安装 | 免费 Expo 账号 |
| iOS | Mac 上 `npx expo run:ios --device`，用免费 Apple ID 签名装到自己 iPhone | Mac + Xcode + 免费 Apple ID；7 天后要重新装 |

iOS 不用 EAS 云打包：EAS 给真机出 iOS 包需要付费 Apple 开发者账号（99 美元/年），和"不上架"的目标不符。

## 数据格式

AsyncStorage 键 `ledger.v1`，值是 JSON：

```json
{ "version": 1, "entries": [
  { "id": "…", "type": "expense", "amountCents": 2350, "category": "餐饮",
    "note": "午饭", "date": "2026-11-02", "createdAt": 1793600000000 }
] }
```

- 金额用**整数分**存，避免 `0.1 + 0.2` 这类浮点误差。
- `date` 存本地日期字符串，按月筛选只比较前 7 位。

## 代码结构

- `src/ledger.ts`：纯函数。解析金额、格式化、按月筛选、汇总、分组、序列化与校验。不依赖 React Native，可以直接单测。
- `src/storage.ts`：读写 AsyncStorage。
- `App.tsx`：唯一一个界面。

## 风险和回滚

| 风险 | 处理 |
|---|---|
| 存储里的数据损坏或格式不认识 | 读取失败时不覆盖：先把原文备份到 `ledger.v1.corrupt`，再提示用户，从空列表开始 |
| 两次保存交错，后写的覆盖先写的 | 状态以内存里的列表为准，每次保存写整份最新列表 |
| 用户输入 `1.234`、`abc`、`0` | `parseAmount` 拒绝：最多两位小数、必须大于 0、不超过 1 亿 |
| iOS 免费签名 7 天过期 | 写进交接文档；过期后在 Mac 上重新运行一次 |

回滚：这是新仓库，不影响其他项目。

## 怎么验证

1. `npm run check`：类型检查 + 单元测试（`src/ledger.ts`、`src/storage.ts`）。
2. `npx expo export --platform android`：确认能打出 JS 包。
3. 真机：按 [docs/guides/真机调试.md](../guides/真机调试.md) 用 Expo Go 扫码，记一笔、杀掉 App 再打开，数据还在。
4. 打包：按 [docs/guides/打包安装.md](../guides/打包安装.md) 装 APK / 装到 iPhone。
