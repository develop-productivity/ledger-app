# v1.2.0：上架准备

2026-11-08 · 作者：Claude · 状态：已实现

## 问题

用户定了上架路线：先 Uptodown，再 Google Play（[决定](../decisions/2026-11-08-store-route.md)）。现在还缺这些东西：

1. 图标和启动图还是 Expo 模板的默认图片，商店审核和用户第一眼都会看到。
2. 没有隐私政策网址。两个商店都要填。
3. 没有商店文案、截图、Google Play 的置顶大图。
4. 发版流程只出 APK。Google Play 只收 AAB。
5. 没有上架步骤的指南。上架要人在网页后台操作，要有能照着做的步骤。

## 方案

| 项 | 做法 |
|---|---|
| 图标 | 自己画：蓝色渐变底，白色账页加一个三色环形图（对应 App 里的饼图）。先写 SVG 源文件（`assets/source/`），再用无头浏览器导出 PNG。Android 自适应图标的前景缩到安全区（中间 66%）以内，另出一张单色图给主题图标用 |
| 启动图 | 加 `expo-splash-screen` 插件，蓝色背景（`#4C6EF5`）加图标，宽 200 |
| 隐私政策 | 仓库根目录的 `PRIVACY.md`，中英双语。网址用 GitHub 的文件页面 |
| 商店素材 | `docs/store/`：文案（中英）、512 图标、1024×500 置顶大图、4 张 1080×1920 截图（JPEG，每张 150 KB 以内）、数据安全表的回答 |
| AAB | `eas.json` 加 `production` 配置（`app-bundle`）。加一个**手动触发**的工作流 `play-aab.yml`：输入已发布的 tag，检出这个 tag，打 AAB，把下载链接写进运行摘要 |
| 指南 | `docs/guides/上架Uptodown.md`、`docs/guides/上架GooglePlay.md` |
| 版本 | 1.2.0，versionCode 3 |

### 方案对比

| 问题 | 选用 | 没选 | 理由 |
|---|---|---|---|
| 隐私政策放哪 | GitHub 文件页面 | GitHub Pages 独立网页 | 不用开 Pages、不用多一个部署；两个商店都只要一个能公开访问的网址 |
| AAB 怎么打 | 手动触发的工作流 | 每次推 tag 时 APK、AAB 一起打 | 每次打包都占 EAS 免费额度。Play 账号还没注册，AAB 现在用不上；上传 Play 时再点一下就行 |
| AAB 怎么传到 Play | 人在 Play Console 手动上传 | `eas submit` 自动上传 | Google 要求第一次必须手动上传；自动上传还要建服务账号、存一个新密钥。更新频繁后再做 |
| 截图怎么来 | 浏览器按手机尺寸渲染，再加标题和边框 | 真机截图 | 这台 WSL 连不了手机；网页和真机用的是同一套界面代码。装上 v1.2.0 后可以换成真机截图 |

### 不做

- **数据导出和备份**：调研建议上架前补上，但不是商店的硬性要求。下一个版本单独做，免得这个 PR 太大。商店描述里写明"卸载会删除全部记录"。
- **英文界面**：App 只有中文。英文商店描述里写明界面是中文。
- **国内商店、iOS**：决定里已经排除。

## 风险和回滚

| 风险 | 处理 |
|---|---|
| 新加的 `expo-splash-screen` 是原生模块，打包后才知道效果 | 它是 Expo Go 自带的模块，Expo Go 里照常能跑。启动图效果要在 v1.2.0 的 APK 上看 |
| 图标在某些桌面上被裁切 | 前景已经缩到安全区内，并按圆形遮罩预览过。装上后在真机桌面上再看一眼 |
| Play 签名密钥和 APK 不同，用户不能跨渠道升级 | 指南里列出两种选法和代价，到上传那一步由用户选（需要人判断） |
| 隐私政策写"不联网"，以后加了联网功能忘了改 | 政策里写了"有变化时更新本页"；以后加联网功能时要同时改 `PRIVACY.md` 和商店的数据安全表 |

回滚：图标和启动图回退到上一个提交的 `assets/` 和 `app.json`；删除 `play-aab.yml`。已经发出去的版本号不回收，发下一个补丁版本。

## 怎么验证

1. `npm run check` 通过；`npx expo config` 能正确读出启动图配置。
2. 本 PR 的 CI `check` 通过（会导出一次 Android 包）。
3. 合并后推 `v1.2.0` tag，装上 APK，人工检查：
   - 桌面图标是新图标，圆形和方形遮罩下都不被裁到；
   - 打开时显示蓝色启动图，然后进入明细页；
   - 从 v1.1.0 或 v1.0.0 覆盖安装，原来的记录都还在。
4. 在 Actions 页面手动运行一次 **Google Play AAB**，确认摘要里有 AAB 下载链接。
